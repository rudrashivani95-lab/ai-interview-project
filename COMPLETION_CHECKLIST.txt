   • Result: Requests never reached the server

☑ Missing API Prefix Identified

   • Result: Routes wouldn't be found even if port was correct

☑ Unsafe Port Default Identified
   • Backend: defaulting to port 6000
   • Issue: Port 6000 is blocked by browsers
   • Result: System wouldn't work even with correct config
