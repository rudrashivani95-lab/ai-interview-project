PROBLEM REPORTED
═══════════════════════════════════════════════════════════════════════════════
User received "400 Bad Request" error when attempting to login with a newly
created account. The authentication system appeared to be failing even though
accounts were being created.

ROOT CAUSES IDENTIFIED
═══════════════════════════════════════════════════════════════════════════════

1. PORT MISMATCH (PRIMARY CAUSE)
   ❌ Frontend configured: http://127.0.0.1:5000
   ✅ Backend running on:  http://127.0.0.1:3000
   
   Impact: Frontend requests never reached the backend, resulting in connection
           errors that appeared as 400 Bad Request errors.

2. MISSING API PREFIX
   ❌ Frontend called: /auth/login, /auth/signup
   ✅ Should call:    /api/auth/login, /api/auth/signup
   
   Impact: Even if port was correct, routes wouldn't be found.

3. UNSAFE PORT IN BACKEND
   ❌ Default port:  6000 (blocked by browsers)
   ✅ Changed to:    3000 (safe port)
   
   Impact: Port 6000 is reserved and blocked by all modern browsers.

TROUBLESHOOTING GUIDE
═══════════════════════════════════════════════════════════════════════════════

Error: "Connection Refused on Port 3000"
  └─ Solution: Make sure backend is running with 'npm start'

Error: "Cannot GET /api/auth/login"
  └─ Solution: Check that config.js has correct port 3000

Error: "CORS Error" in browser console
  └─ Solution: Verify frontend is on port 5500 (use Live Server)

Error: "MongoDB connection failed"
  └─ Solution: Check MongoDB is running on localhost:27017

Error: "Invalid credentials" when using correct password
  └─ Solution: Check password wasn't changed, try signup again
